Sources

A Python script on GitHub Actions reads every source with ordinary HTTPS requests: no login, no browser. Tap a source to see what it calls.

Luma
Site
luma.com
Checked
Every 3 hours
How
GET requests to Luma's JSON API at api.lu.ma: /discover/get-paginated-events for events near campus, /calendar/get-items for each followed calendar, and /user/profile/events-hosting for each organizer.
Gets
Title, time, venue and map location, host, description, cover image, free or paid.
Found by
Three ways:
  1. Luma's discover feed: the events nearest campus, plus its AI, Tech, Climate and Arts feeds.
  2. 48 calendars and 17 organizer profiles followed by name: campus clubs and programs, and Bay Area tech, startup and hackathon groups. The list is in sources.toml.
  3. Automatically: once an organization's calendar has two events within 3 km of campus in the discover feed, all of its events are followed. It's dropped after 120 days with no events near campus.

Club & department calendars
Site
CalLink
Checked
Every 6 hours
How
A GET request to each of about 60 public feeds: the calendar's iCal (.ics) file, its RSS feed, its WordPress or Localist events API (JSON), or the event data (JSON-LD) embedded in its calendar page.

Club Instagram
Site
instagram.com
Checked
Each club about every 9 days
How
A POST request to Apify's API (api.apify.com) starts its Instagram post scraper on a list of club accounts; the posts come back as JSON.
Gets
Date, time, room and free food from the caption ("GBM Thursday 10/29 7pm in Soda 306"). An event link in the caption is followed to the full event.
Found by
The Instagram handle on each club's CalLink profile, about 880 accounts.

How events are tagged

Every event goes through the same fixed rules, whatever the source.

Location

The first rule that fits decides:

  1. Marked online: Online.
  2. Has map coordinates: within 1.3 km of the center of campus is Campus; within 4 km, or the city is Berkeley, is Berkeley. More than 110 km away is not listed.
  3. Has a city: Berkeley; Oakland, Emeryville, Albany, Richmond, Alameda, Walnut Creek and 19 other East Bay cities are East Bay; San Francisco; Palo Alto, Stanford, Mountain View, San Jose and 18 other cities are Peninsula & South Bay.
  4. Coordinates but an unknown city: west of longitude −122.36 between latitudes 37.70 and 37.82 is San Francisco; north of 37.95 is North Bay; south of 37.70 is Peninsula & South Bay; anything else is East Bay.
  5. No location at all: Berkeley if it came from a club or campus calendar, a mailing list or Instagram, since those are local. From anywhere else it is not listed.

Auto tagging

The title, description, host and any category the source gives (such as the campus calendar's event type) are searched for the keywords below, ignoring case. An event gets every tag with a match, so it can have several or none. A keyword also matches longer words ("recruit" matches "recruiting"), except short ones like AI, DJ or run, which must be whole words.

Free

Listed as free or $0 by the source, or the description says free admission, free entry, free event, free to attend or no cost. Free only shows these.

Source

Where the event was found. The same event found in several places is merged into one, and the card shows every source.

Code

Code at GitHub. Event data is available on request through the form.
