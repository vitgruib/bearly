Events Sources Code

Bearly Missed.

Every few hours a scraper reads the places Berkeley events get posted and merges them into one list. Anyone can add a calendar or report an event. The code is on GitHub.

Sources

Tap a source to see how it's read.

Luma
Checked
Every 3 hours
How
Luma's JSON API (api.lu.ma): the discover feed around campus and its AI, Tech, Climate and Arts categories; each followed calendar's events; and the events of organizers who host from a personal account.
Gets
Title, time, venue and map location, host, description, cover image, free or paid.
Found by
About 25 campus-org calendars, 25 Bay Area tech calendars and 17 organizer profiles listed by hand. Any calendar the discover feed shows hosting near campus is added automatically.
UC Berkeley Events
Checked
Every 6 hours
How
The JSON API behind events.berkeley.edu (LiveWhale), one day at a time.
Gets
Title, time, room and building, department, description, image, event type, cost.
Found by
It's the official campus calendar. Gym hours, daily exhibits and away games are left out.
Club & department calendars
Checked
Every 6 hours; unchanged calendars cost one "not modified" check
How
About 60 public feeds, each in its own standard format: Google Calendar and other iCal (.ics) feeds, RSS, schema.org event data in a page, and the WordPress, Localist and FullCalendar event APIs.
Gets
Title, time, location, description, and image where the feed has one.
Found by
Student-org Google Calendars linked from CalLink (the official club directory) and embedded on club sites hosted by OCF; the Haas clubs feed (about 40 clubs); and departments and nearby institutions such as Berkeley Law, the iSchool, the Simons Institute, BAMPFA, the Botanical Garden and the Berkeley Public Library. Anyone can add one.
Club Instagram
Checked
Daily, 100 accounts at a time, so each club about every 9 days
How
Apify's Instagram Post Scraper (a paid API, capped at $5 a month), asking only for posts since that account was last read.
Gets
Date, time, room and free food from the caption, read by a rule-based parser ("GBM Thursday 10/29 7pm in Soda 306"). A Luma or Partiful link in the caption is followed to the full event.
Found by
The Instagram handle on each club's CalLink profile, about 880 accounts.
Mailing lists
Checked
Every 3 hours
How
IMAP, reading an inbox subscribed to department and club listservs such as eecs-ugrads.
Gets
Event links in each email are followed to the full event. Announcements without a link go through the same parser as Instagram captions.
Found by
Subscribing the inbox to a list.
Cerebral Valley
Checked
Every 6 hours
How
Cerebral Valley's public events API, which lists every approved event; its events page shows only 20.
Gets
Title, time, venue, city, description, image, event type.
Found by
It's the main Bay Area AI community calendar.
Partiful
Checked
Every 6 hours
How
Partiful has no public search, so the Bay Area "trending" section of partiful.com/explore is read from the page's embedded data.
Gets
Title, time, venue and address, description, image, free or paid.
Found by
Trending events, plus any partiful.com/e/ link found in another source.
Hackathons
Checked
Daily
How
Devpost's hackathon API, then each candidate's page; the Y Combinator, MLH and AGI House event listings.
Gets
Title, dates, venue and address, host, description, image.
Found by
Those four platforms, kept to in-person Bay Area hackathons. Month-long online submission windows are skipped.
Music & venues
Checked
Every 12 hours
How
Whatever each venue's own calendar reads: VenuePilot's GraphQL API (Ashkenaz, Ivy Room), schema.org data on the Fox and Greek pages, the UC Theatre's show pages, Resident Advisor's GraphQL API, and DoTheBay venue pages as JSON.
Gets
Show name, time, venue and address, description, image, price.
Found by
East Bay venues listed by hand, plus 17 more through DoTheBay. A show listed by both a venue and an aggregator is merged.
Added by students
Checked
Every 3 hours
How
Each approved link is fetched like a link in an email (Luma, Partiful, Eventbrite, Meetup and other event pages).
Gets
The full event from its page, refreshed each time so changes show up.
Found by
The form or a GitHub issue, approved by a maintainer.

Code

Everything is at github.com/vitgruib/bearly: the scrapers in scraper/sources/, every calendar and club in sources.toml and clubs/instagram.txt, and this site in site/. The current data is public too: events.json.

Add a source

Anyone can add a calendar (a public Google Calendar, a Luma calendar, an .ics or RSS feed, or an events page) or a single event. A maintainer approves everything before it goes up.

  • On GitHub (free account): add a calendar or add an event. A bot replies within a minute with what it found.
  • Google Form (no account). Checked within half an hour, but there's no reply.

Every event has a Report link for spam, cancellations and mistakes.
