Events Sources & Code

Bearly Missed.

Every few hours a scraper reads the places Berkeley events get posted and merges them into one list. Anyone can add a calendar or report an event. The code is on GitHub.

Sources

Tap a source to see how it's read.

Luma
Checked
Every 3 hours
How
Luma's JSON API: the discover feed around campus, followed calendars, and organizer profiles.
Gets
Title, time, venue and map location, host, description, cover image, free or paid.
Found by
About 70 calendars and organizers listed by hand, plus any calendar the discover feed shows hosting near campus.
UC Berkeley Events
Checked
Every 6 hours
How
The JSON API behind events.berkeley.edu.
Gets
Title, time, room and building, department, description, image, event type, cost.
Found by
It's the official campus calendar.
Club & department calendars
Checked
Every 6 hours
How
About 60 public feeds: Google Calendar and other iCal feeds, RSS, and event data on calendar pages.
Gets
Title, time, location, description, and image where the feed has one.
Found by
Club calendars linked from CalLink and club websites, the Haas clubs calendar, and departments and nearby institutions such as Berkeley Law, BAMPFA and the Berkeley Public Library. Anyone can add one.
Club Instagram
Checked
Each club about every 9 days
How
Apify's Instagram scraper reads each club's recent posts.
Gets
Date, time, room and free food from the caption ("GBM Thursday 10/29 7pm in Soda 306"). An event link in the caption is followed to the full event.
Found by
The Instagram handle on each club's CalLink profile, about 880 accounts.
Mailing lists
Checked
Every 3 hours
How
An inbox subscribed to department and club listservs, read over IMAP.
Gets
The full event from any event link, otherwise the date, time and room from the email.
Found by
Subscribing the inbox to a list.
Cerebral Valley
Checked
Every 6 hours
How
Cerebral Valley's public events API.
Gets
Title, time, venue, city, description, image, event type.
Found by

Partiful
Checked
Every 6 hours

Hackathons

In-person Bay Area hackathons on those four platforms.
Music & venues
Checked
Every 12 hours
How
Each venue's own calendar (Ashkenaz, Ivy Room, the Fox, the Greek, the UC Theatre), Resident Advisor, and DoTheBay.
Gets
Show name, time, venue and address, description, image, price.
Found by
East Bay venues listed by hand, plus 17 more through DoTheBay.
Added by students
Checked
Every 3 hours
How
Each approved event link (Luma, Partiful, Eventbrite, Meetup...) is read from its page.
Gets
The full event from its page.
Found by
The form or a GitHub issue, approved by a maintainer.

Code

Code at GitHub. Event data is available on request through the form.

Add a source

Add a calendar or a single event with the Google Form. A maintainer approves everything before it goes up. You can also open a pull request on GitHub.

Every event has a Report link for spam, cancellations and mistakes.
